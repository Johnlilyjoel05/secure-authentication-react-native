Project Overview:
   A secure mobile authentication system developed using React Native and Firebase Authentication that integrates multi-factor authentication, email verification, and biometric login (fingerprint/PIN) to protect user accounts from unauthorized access. The system implements secure credential storage, encrypted session handling, and password recovery mechanisms to enhance account security in modern mobile applications.

Features:
  1. User registration with email verification
  2. Secure login authentication
  3. Biometric authentication (fingerprint / PIN)
  4. Multi-factor authentication (MFA)
  5. Password recovery via email
  6. Secure session management
  7. Encrypted credential storage
  These mechanisms help mitigate threats such as brute-force attacks, credential theft, and unauthorized account access, improving overall application security.

Technologies Used:
  1. React Native
  2. Firebase Authentication
  3. JavaScript
  4. React Native Secure Storage
  5. JSON Web Tokens (JWT)
